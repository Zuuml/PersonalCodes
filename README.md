# FORGED — стартовый сайт

Готовая статическая версия сайта, которую можно открыть и опубликовать даже с телефона.

## Файлы

- `index.html` — структура и тексты сайта.
- `style.css` — весь внешний вид и адаптация под телефон.
- `script.js` — меню, анимации появления и параллакс.
- `README.md` — эта инструкция.

## Как посмотреть сайт на телефоне

Самый простой путь — загрузить эти 4 файла в GitHub-репозиторий и включить GitHub Pages
или подключить репозиторий к Cloudflare Pages.

## Что поменять в первую очередь

В `index.html`:
1. `FORGED` — название бренда.
2. `https://t.me/your_username` — ссылка на ваш Telegram.
3. `+7 000 000-00-00` и `tel:+70000000000` — телефон.
4. Тексты в секциях — на свои.
5. Ссылки `https://images.unsplash.com/...` — на ваши фотографии.

В `style.css`:
- `--accent: #d8ff3e;` — главный акцентный цвет.
- `--bg: #080808;` — основной фон.

## Публикация через GitHub Pages с телефона

1. Откройте github.com и войдите в аккаунт.
2. Создайте новый репозиторий, например `forged-site`.
3. Загрузите `index.html`, `style.css`, `script.js`.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch.
6. Branch: `main`, папка `/ (root)`, затем Save.
7. Через интерфейс GitHub появится адрес опубликованного сайта.

## Важно

Фотографии в шаблоне загружаются с Unsplash и используются только как демонстрационные.
Для рабочего коммерческого сайта замените их своими фотографиями и логотипом.

Сайт не требует PHP, базы данных, npm или сборки.
